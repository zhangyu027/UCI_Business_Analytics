# UCI Business Analytics — Final Project

This folder contains course final-project instructions, example datasets, code notebooks, presentation examples, and reference reports.

## Folder guide

- **01_Project Guidelines/** — project instructions, presentation requirements, topics, and overview.
- **02_Project Datasets/** — datasets for student analysis. Check dataset documentation and licensing before reuse.
- **03_Codebooks/** — example Python notebooks and scripts. Some notebooks may reference data paths from the earlier folder layout; update those paths before running.
- **04_Presentation Demos/** — example presentation slides and PDFs.
- **05_Reference Reports/** — rendered notebook reports and other examples.

## Important notes

- The final-group presentation roster remains at the root pending privacy review. **This repository is public**: do not place student names, grades, or other confidential information in this repository. A folder named “Instructor Only” would not restrict access.
- Existing duplicate/reference files in the original codebook have been retained where their purpose is unclear. Review duplicates before removing any.
- Some existing file names and paths have changed. Update links and notebook references as needed.
- Large video recordings are intentionally not included in this folder.

## Suggested student workflow

1. Read the project guidelines.
2. Choose a dataset and define a business question.
3. Explore and analyze the data, using codebooks only as references.
4. Prepare a presentation explaining methods, findings, limitations, and business recommendations.
